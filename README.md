# Student Management System

A full-stack Student Management System that allows users to manage student records through a simple web application.

## Features

- Add new students
- View all students
- Delete students
- REST APIs for student management
- MySQL database integration
- React frontend
- Spring Boot backend

## Tech Stack

### Frontend
- React.js
- JavaScript
- HTML
- CSS
- Axios

### Backend
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- REST API

### Database
- MySQL
